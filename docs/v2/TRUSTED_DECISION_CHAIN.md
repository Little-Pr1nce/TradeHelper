# TradeHelper 2.0 可信决策主链

> 状态：当前 P0 产品合同。它补充 V2-3、V2-5、V2-9 和 V2-11，不改变数据源、风控硬约束或 LLM 边界。

## 1. 用户要得到的答案

系统必须依次回答：

1. 本次使用了哪只股票、哪个交易日、什么价格和哪些来源？
2. 预测模型认为未来 1/3/5/10 个交易日可能怎样走，目标日期是哪天？
3. 预测模型过去准不准；失败是行情不足，还是模型能力不足？
4. 在该预测情景下，哪些策略适用；同一股票上历史表现最好的是哪一个？
5. 保守和激进方案分别如何操作、亏多少失效、什么条件触发？
6. LLM 研究员是否提出不同观察，代码系统如何验证？
7. 最终为什么给出当前结论，预测和策略各自承担什么责任？

固定主链：

```text
可核对的历史/当前事实
  -> 股票级预测候选 OOF
    -> 冻结预测结果与情景
      -> 同情景下策略候选 OOF
        -> 股票级策略 Champion/观察 fallback
          -> 风控与组合分配
            -> 保守/激进操作计划
              -> LLM 独立观察
                -> 通俗报告与三本账
```

## 2. 三本账不得混合

### 预测账

评价未来方向概率和收益区间。主指标为方向正确率、Brier、Log Loss、校准误差和 80% 收益区间命中。报告主视图只显示通俗结论；技术指标放在历史可信度明细。

### 策略账

在预测和情景已经冻结的前提下，评价策略触发、成交和退出。至少显示净收益、胜率、最大不利波动、最大有利波动、基准收益和交易成本。

### 联合账

评价预测、策略、风控、组合分配和成交约束合在一起后的最终结果。至少显示组合收益、买入持有基准、收益保留率、最大回撤、Sharpe 和 Calmar。

用户必须能区分：预测错误、预测正确但策略错误、策略正确但被风控降级，以及完整链路有效。

## 3. 策略选优不是只看 Alpha

策略候选可通过两条并列路径晋级：

- 绝对超额通道：多数顺序 OOF 分段取得正超额收益。
- 风险调整通道：正收益市场中保留至少 80% 基准收益，同时最大回撤改善至少 30%、Sharpe 改善至少 0.20。

两条通道都必须满足至少 30 个 OOF 成交、至少 3 个顺序测试折、平均净收益为正、bootstrap 下界不为负，并计入手续费、税费、滑点和市场规则。

## 4. 四种状态必须分开

报告和 UI 禁止使用笼统的“数据/证据不足”覆盖以下状态：

| 状态 | 含义 | 正确表达 |
|---|---|---|
| 行情完整度 | 日 K、实时报价、日期和来源是否可用 | 行情完整/缺少实时价/历史不足 |
| 预测训练准备度 | 每周期成熟样本、特征覆盖是否够训练 | 可训练/上市时间短/样本不足 |
| 预测模型质量 | OOF 是否校准、是否优于或不劣于基线 | 模型通过/校准失败/未证明有效 |
| 策略历史质量 | 是否完成成交回放并有足够样本 | 正期望/负期望/回放尚未完成 |

有充足 K 线但模型未通过时必须写：

> 行情数据完整、训练样本充足；当前候选模型在未见历史区间表现未达门槛。这是模型能力问题，不是行情缺失。

新闻或基本面没有历史时点数据时，只允许写明该类特征未进入历史训练。当前纯技术模型仍必须用已有 K 线完成 OOF；不能以新闻/基本面缺失为模型表现差开脱。

## 5. 历史数据边界

- 已完成日 K 可以用于重建点时技术特征和预测/策略 OOF。
- 当前新闻、当前基本面不得倒填到历史日期。
- 从系统开始持续保存后的新闻和基本面快照，可在其首次可见时间之后进入未来训练。
- 没有历史新闻/基本面不阻止纯技术候选训练，只限制模型解释范围。
- 新股按上市日期裁剪；样本确实不足时提供经验基线，但不得称为正式模型。

## 6. Tab1 和 Tab3 报告顺序

两类报告共用以下自然阅读顺序：

1. **基本信息与数据核对**：公司、代码、市场、价格、交易日、来源、持仓成本。
2. **未来走势预测**：目标日期、方向概率、预计收益范围、通俗理由、历史验证状态。
3. **策略选择与历史表现**：预测情景、选中策略、收益、基准、回撤和为什么选它。
4. **保守与激进操作计划**：当前动作、触发条件、股数、止损、止盈、最大亏损、失效和有效期。
5. **研究员观察**：LLM 观点、系统确认/反驳/待验证；不直接下单。
6. **最终结论**：现在做什么、等待什么、判断错在哪里退出。
7. **历史可信度**：预测账、策略账和联合账的通俗成绩；详细术语放在可展开明细。

Tab3 仍必须额外先处理持仓风险、账户现金、集中度和关注股替换，不能退化成 Tab1 批量版。

## 7. 完成标准

- 当前分析和历史回放使用同一 ForecastResult -> TradingScenario -> TradePlan -> ExecutionDecision 路径。
- 每只股票始终有经验基线结果；正式模型只有通过 OOF 后才参与新增风险。
- 每个可执行策略都有股票级历史表现；没有成熟回放时明确写“规则候选，尚未证明正期望”。
- 报告不以 OOF、ECE、Alpha、Champion 等英文术语作为主结论。
- A股和美股、Tab1 和 Tab3、盘前/盘中/盘后均通过同一验收矩阵。

## 8. 当前落地状态（2026-07-20）

- 股票级预测、情景、策略、风控、组合分配、订单和成交已由生产后台按三折顺序历史重放连接，不再是彼此独立的展示模块。
- 预测账保存方向概率和区间表现；策略账保存同股票、同参数、同档案的触发成交表现；联合账保存保守/激进完整链路的收益、基准和逐日回撤。
- 报告消费股票级汇总，不展开数百条原始事件，也不会把同市场其他股票的联合结果归给当前股票。
- 当前联合历史结果仍是单股票标准研究账户实验；真实多股票连续组合 OOF、策略 challenger 的生产晋级调度和 bootstrap 区间仍属于 P0，不能在完成前宣传为全自动盈利系统。
